AI Notes

AI-powered note-taking application built with SwiftUI and Core Data.
This app supports smart note management with Apple ML features such as NLP-based summarization, keyword extraction, automatic tag prediction, language detection, and voice note input using Speech API.

AI Notes 🧠📒

AI Notes is an intelligent note-taking application developed with SwiftUI and Core Data.
The app uses Apple’s Machine Learning frameworks to provide smart productivity features such as note summarization, keyword extraction, language detection, automatic tag suggestions, and voice note input.

✨ Features
📝 Create, edit, and delete notes
🤖 AI-powered note summarization
🔍 Automatic keyword extraction
🏷️ Smart tag prediction system
🌍 Language detection
🎤 Voice-to-text note creation
🌙 Dark mode support
📂 Dynamic tag filtering
👤 User profile page
💾 Local data storage with Core Data
📱 Modern and responsive SwiftUI UI
🛠️ Technologies Used
SwiftUI
Core Data
Apple Natural Language Framework
Speech Framework
MVVM Architecture
🚀 Project Goal

AI Notes aims to combine modern iOS development with on-device AI technologies to create a smarter and more productive note-taking experience.
